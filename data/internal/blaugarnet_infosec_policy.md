# Blaugarnet Services Inc. — Information Security Policy (summary for delivery staff)
**Version 3.2 · 2026-03 · Owner: Security Office**

- Client data only in client-approved environments; never on personal devices. Laptops full-disk encrypted, managed via MDM.
- Access follows least privilege; production access requires a ticket and expires in 14 days.
- Blaugarnet Services holds SOC 2 Type II (renewed 2026-02). Report shareable under NDA via the Security Office only — never attach it to email.
- Regulated-data engagements (PHI, PCI, banking) require the engagement security addendum and a named security reviewer at design sign-off.
- Incidents: report within 1 hour to security@blaugarnetservices — the clock matters contractually.
