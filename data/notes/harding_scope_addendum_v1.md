# Scope Addendum — Harding Outfitters Phase One
**Version 1 · 2026-08-07**
**Status:** draft for client review

Following the 2026-08-05 scoping session, phase one scope is proposed as follows.

## Phase one — in scope
1. Customer returns portal: order lookup, item-level return initiation, reason codes, photo upload for damage claims, status visibility.
2. Agent work queue: unified queue, assignment, refund/exchange proposal and approval workflow.
3. OrderHub integration: order lookup, refund execution and write-back, nightly reconciliation.
4. Staff single sign-on via Okta (OIDC), three staff roles.
5. **Instant exchanges**: replacement shipment initiated on return approval, before the returned item is received, with configurable credit-risk rules.
