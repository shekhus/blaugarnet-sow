# Scope Addendum — Harding Outfitters Phase One
**Version 2 · 2026-08-18 · Supersedes v1 (2026-08-07)**
**Status:** out for signature

Following Harding's internal review (J. Morrow email, 2026-08-12) and the OrderHub platform upgrade freeze, phase one scope and timeline are amended as follows.

## Phase one — in scope
1. Customer returns portal: order lookup, item-level return initiation, reason codes, photo upload for damage claims, status visibility.
2. Agent work queue: unified queue, assignment, refund/exchange proposal and approval workflow.
3. OrderHub integration: order lookup, refund execution and write-back, nightly reconciliation.
4. Staff single sign-on via Okta (OIDC), three staff roles.
5. Data migration support per the agreed responsibility split (Harding: extraction and cleanup; Blaugarnet Services: transformation and load; joint validation).

## Phase one — out of scope (deferred to phase two)
- Instant exchanges and associated credit-risk rules
- Analytics dashboard
- Any auto-approved refunds

## Timeline
- Kickoff: 2026-09-15
- UAT: 2026-11-30 – 2026-12-11, extended regression window 2027-01-06 – 2027-01-12
- Production go-live: **2027-01-15**
- OrderHub vendor API change freeze (2026-12-01 – 2027-01-05) and Harding holiday production freeze (2026-12-15 – 2027-01-01) are acknowledged constraints.

## Effort
Approximately 2,400 hours across the Blaugarnet Services team. Commercial terms per the SOW and MSA.
